# 🤖 Mini AI ChatBot

A modern and responsive AI-inspired chatbot built using **HTML, CSS, JavaScript, and Python (Flask)**. This project features a beautiful user interface, quick reply buttons, typing animation, timestamps, and predefined intelligent responses.

---

---

## ✨ Features

-  Beautiful ChatBot Interface
-  Interactive Chat Window
-  Quick Reply Buttons
-  Enter Key Support
-  Send Button
-  Typing Animation
-  Message Time Stamp
-  Reset Chat Button
-  Auto Scroll
-  Modern Glassmorphism UI
-  Fully Responsive Design
-  Flask Backend

---

## 🛠️ Tech Stack

- HTML5

- Flask

## 🚀 Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/amaniyar978-maker/mini_ai_chatbot.git
```

### 2️⃣ Open Project

```bash
cd mini_ai_chatbot
```

### 3️⃣ Install Flask

```bash
pip install flask
```

### 4️⃣ Run the Project

```bash
python app.py
```

### 5️⃣ Open Browser

```
http://127.0.0.1:5000
```
